# Bootcamp 2020 HTML Practice Page

This repository preserves a minimal HTML exercise from Umer Sajid’s 2020 bootcamp work. It is a small, client-side page intended to document an early web-development step—not a production website, data-science project, or deployed application.

## Contents

| File | Purpose |
| --- | --- |
| `index.html` | A single semantic HTML page with responsive metadata and a short archive message. |
| `.github/workflows/main.yml` | Credential-free GitHub Actions checks that confirm the page exists and retains its expected title. |

## Run locally

Open `index.html` directly in a browser, or serve the repository directory with a local static server:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Historical workflow note

The original workflow was an early Surge deployment experiment using deprecated action versions, Node 10, and a misspelled secret reference. It has been replaced with a build-free HTML validation workflow. No deployment token is required, and no hosting or production deployment is claimed.
